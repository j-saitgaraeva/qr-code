# QR Code Generator с автообрезкой

**Генератор QR-кодов** с **H-коррекцией (30%)** и **автоматической обрезкой canvas** для идеальных PNG без отступов.

## ✨ Особенности

- **QRCodeStyling.js** — современная библиотека
- **H-уровень коррекции** — запас 30% для наложения логотипов
- **Автообрезка** — убирает все прозрачные отступы
- **Адаптивный размер** — код растет под длину данных
- **Длина ссылки** — без ограничений, любое количество символов
- **Умное имя файла** — в имя файла помещается название ссылки
- **Скачивание PNG** — чистый результат без фона
- **Валидация символов** — максимум 2000 симвлов. Пробелы в начале и в конце фраз обрезаются

## 🖥️ Платформы

Сервис сделан для работы на десктопе. На мобилке тоже функционирует, но до конца не адаптирован к ней

## 📁 Структура проекта

- index.html — Интерфейс (input + кнопка + контейнер)
- script.js — Логика генерации, обрезки, скачивания
- styles.css — Современный дизайн
